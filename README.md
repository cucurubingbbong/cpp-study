# C++ 공부

게임 클라이언트 개발을 위한 C++ 기초와 메모리 관리, STL 사용을 직접 코드로 연습하는 레포입니다.

## 학습 순서

- [ ] 기본 문법: 변수, 함수, 클래스, `const`, 참조
- [ ] OOP: 생성자/소멸자, 상속, 다형성, `virtual`
- [ ] 메모리: 스택/힙, 포인터, RAII, `unique_ptr`
- [ ] STL: `vector`, `unordered_map`, `string`, 반복자, 알고리즘
- [ ] 현대 C++: `enum class`, 람다, 이동 의미론 기초
- [ ] 작은 예제를 자료 없이 다시 작성

## 기록 방식

주제별로 코드와 짧은 설명을 함께 남깁니다. 실행/빌드 명령은 예제를 추가할 때 해당 폴더의 README에 기록합니다.

코딩 테스트 풀이는 별도의 [Programmers 레포](https://github.com/cucurubingbbong/Programmers)에 기록합니다.
