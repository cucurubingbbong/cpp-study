# 반복문

## 반복문의 종류

C++ 반복문은 크게 다음 3가지가 있다.

* `for`
* `while`
* `do-while`

---

# for문

```cpp
for (초기화; 조건; 증감)
{
    반복할 코드
}
```

실행 순서:

```text
초기화
  ↓
조건 검사
  ↓
반복할 코드
  ↓
증감
  ↓
조건 검사
  ↓
반복...
```

예:

```cpp
for (int i = 0; i < 5; i++)
{
    std::cout << i << '\n';
}
```

`i`가 `0`부터 시작해서 `5`보다 작은 동안 반복한다.

```text
0
1
2
3
4
```

보통 **반복 횟수가 비교적 명확할 때** 사용한다.

---

# while문

```cpp
while (조건)
{
    반복할 코드
}
```

조건이 `true`인 동안 계속 반복한다.

```cpp
int i = 0;

while (i < 5)
{
    std::cout << i << '\n';
    i++;
}
```

조건이 계속 `true`라면 무한 반복한다.

```cpp
while (true)
{
    // 무한 반복
}
```

보통 **특정 조건이 참인 동안 계속 반복해야 할 때** 사용한다.

---

# do-while문

```cpp
do
{
    실행할 코드
}
while (조건);
```

`while`문과 비슷하지만 **조건을 검사하기 전에 코드를 먼저 한 번 실행한다.**

즉 조건이 처음부터 `false`여도 최소 한 번은 실행된다.

```cpp
int i = 10;

do
{
    std::cout << i << '\n';
}
while (i < 5);
```

결과:

```text
10
```

보통 **무조건 한 번은 실행되어야 할 때** 사용한다.

---

# 반복문 제어문

## break

현재 반복문을 즉시 종료한다.

```cpp
for (int i = 0; i < 10; i++)
{
    if (i == 5)
    {
        break;
    }

    std::cout << i << '\n';
}
```

결과:

```text
0
1
2
3
4
```

`i == 5`가 되는 순간 반복문 자체가 끝난다.

---

## continue

현재 반복만 건너뛰고 다음 반복으로 넘어간다.

```cpp
for (int i = 0; i < 5; i++)
{
    if (i == 2)
    {
        continue;
    }

    std::cout << i << '\n';
}
```

결과:

```text
0
1
3
4
```

`i == 2`일 때 아래 코드를 실행하지 않고 다음 반복으로 넘어간다.

---

# 중첩 반복문

반복문 안에 다른 반복문을 넣을 수 있다.

```cpp
for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 2; j++)
    {
        std::cout << "i: " << i
                  << ", j: " << j
                  << '\n';
    }
}
```

결과:

```text
i: 0, j: 0
i: 0, j: 1

i: 1, j: 0
i: 1, j: 1

i: 2, j: 0
i: 2, j: 1
```

바깥쪽 `for`문이 한 번 실행될 때마다 안쪽 `for`문이 처음부터 끝까지 실행된다.

```text
i = 0
 ├─ j = 0
 └─ j = 1

i = 1
 ├─ j = 0
 └─ j = 1

i = 2
 ├─ j = 0
 └─ j = 1
```

---

# 반복문 선택

| 반복문        | 주로 사용하는 경우                |
| ---------- | ------------------------- |
| `for`      | 반복 횟수가 비교적 명확할 때          |
| `while`    | 특정 조건이 참인 동안 계속 반복할 때     |
| `do-while` | 조건과 상관없이 최소 한 번은 실행해야 할 때 |

---

# 정리

```text
for
 └─ 반복 횟수가 비교적 명확할 때
 └─ 초기화 → 조건 → 코드 → 증감 → 조건...

while
 └─ 조건이 true인 동안 반복
 └─ 처음부터 조건이 false면 한 번도 실행되지 않음

do-while
 └─ 코드 실행 후 조건 검사
 └─ 무조건 최소 한 번 실행


break
 └─ 반복문 즉시 종료

continue
 └─ 현재 반복만 건너뜀


중첩 반복문
 └─ 반복문 안에 반복문 사용 가능
```
