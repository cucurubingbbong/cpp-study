## C++ 실습: 체력 관리

- [ ] 체력 100으로 시작하기
- [ ] 메뉴 입력 받기: 1은 피해 20, 2는 회복 10, 0은 종료
- [ ] 피해와 회복 처리를 각각 함수로 분리하기
- [ ] 체력은 0~100 범위를 유지하기
- [ ] 참조 전달로 실제 체력 값을 바꾸기
- [ ] 값 전달로 바꿨을 때 결과가 어떻게 달라지는지 확인하기
- [ ] 중단점에서 체력 값이 바뀌는 과정 보기

반복 공격으로 0 아래로 내려가지 않는지, 반복 회복으로 100을 넘지 않는지 확인합니다.

## C# 실습: Strategy

- [ ] `IAttackStrategy`에 `Attack()` 선언하기
- [ ] `SwordAttack`, `BowAttack` 구현하기
- [ ] `Player`가 현재 공격 방식에 행동을 맡기게 만들기
- [ ] 같은 플레이어에서 검 공격을 활 공격으로 바꿔보기
- [ ] 단순한 조건문으로 짰을 때와 무엇이 달라졌는지 두세 줄 적기

C++ 버전은 클래스, 가상 함수, 객체 수명을 배운 뒤 같은 예제로 구현합니다.
